SOFT DELETE (new endpoint, separate from existing hard delete)

Add IsDeleted/DeletedAt fields to Customer model (unavoidable — the flag has to live on the entity). No global query filter added, so existing GetAll/GetById/Delete behavior is untouched.
Add SoftDeleteAsync as a new method in the service — separate from existing DeleteAsync.
Add new endpoint PATCH /api/Customer/{id}/soft-delete.
New migration for the schema change only.
