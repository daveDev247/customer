JWT BEARER TOKEN STEPS
=======================
Install JWT packages (Microsoft.AspNetCore.Authentication.JwtBearer) and a password hasher (BCrypt.Net-Next).
Create User model (credentials) and RefreshToken model (tracks issued refresh tokens so they can be validated/revoked server-side).
Add both as DbSets to AppDbContext, run a migration.
Add JWT settings (secret key, issuer, audience, token lifetimes) to appsettings.json.
Create Auth DTOs: RegisterDto, LoginDto, AuthResponseDto, RefreshTokenRequestDto.
Create IJwtTokenService/JwtTokenService — generates the signed access token and a random refresh token string.
Create IAuthService/AuthService — handles register (hash password), login (verify password, issue tokens), refresh (validate + rotate refresh token), revoke (logout).
Create AuthController with POST /api/auth/register, POST /api/auth/login, POST /api/auth/refresh, POST /api/auth/revoke.
Wire up AddAuthentication().AddJwtBearer() in Program.cs, add app.UseAuthentication() before app.UseAuthorization().
(Follow-up stage, not done now per your instruction not to touch existing endpoints): add [Authorize] to CustomerController once he's comfortable with the auth flow itself.
Use this Powershell command to generate JWT secret key:    [Convert]::ToBase64String((1..64 | ForEach-Object { Get-Random -Minimum 0 -Maximum 255 }))
